# Интерфейс и данные — результат проверки

## Что уже было и сохранено

Строительство через меню, каталог зданий в `src/game/buildings.ts`, размеры 1×1,
2×2, 3×3, предпросмотр, отмена ПКМ/Esc, проверки границ, суши и занятых клеток.
Для нового типа достаточно добавить характеристики в BUILDING_TYPES.
Сохранены движение, выбор рамкой/Shift, создание юнитов и управление камерой.

## Что добавлено

- `src/game/entities.ts`: health/maxHealth поверх существующих hp/maxHp,
  ограничение здоровья при присваивании через health, настраиваемые начальные
  параметры персонажа пятым аргументом createUnit, strength, attackSpeed,
  movementSpeed как совместимое имя существующего speed. Здания поддерживают
  прежний maxHp и новые maxHealth/health.
- `src/game/useRtsGame.ts`: selectedEntities, applyDamage(id, amount),
  destroyEntity(id), selfDestruct(id). Общее удаление обнуляет здоровье,
  снимает выделение, очищает путь и удаляет объект из entities. Занятость
  вычисляется по entities, поэтому клетки освобождаются автоматически.
  Повторное удаление и действие с отсутствующим/невыбранным юнитом безопасны.
  Игровой цикл также удаляет объекты с нулевым здоровьем.
- `src/views/HomePage.vue`: панель характеристик выделенных объектов;
  у каждого выбранного персонажа своя кнопка самоуничтожения.

## Запуск и проверка

Из каталога vue: `npm install`, затем `npm run dev`. Открыть адрес Vite.
Выбрать здание через «Строительство», разместить ЛКМ на свободной суше.
Проверить красный предпросмотр на занятых клетках и за границей карты.
Выбрать персонажа ЛКМ: панель справа внизу показывает характеристики.
Кнопка «Самоуничтожение» удаляет только персонажа соответствующей карточки.
Shift позволяет выбрать несколько объектов и проверить независимое удаление.

Проверка сборки: `npm run build` — успешно.

## Ограничения

Боевой механики в исходном проекте нет: strength и attackSpeed доступны как
характеристики, урон вызывается через applyDamage; новый бой не добавлялся.
Изменять здоровье следует через health/maxHealth и applyDamage; старые поля
hp/maxHp сохранены для совместимости. Визуальная проверка в браузере не выполнялась.
Существующий механизм перемещения зданий не перерабатывался.

## Характеристики по цветам

Настройки находятся в `src/game/unitTypes.ts` и применяются в createUnit
к начальным и создаваемым персонажам. Здоровье/сила/скорость:
синий 100/10/2.5, красный 80/20/2.5, зелёный 150/8/2,
фиолетовый 70/12/3.5, оранжевый 120/15/2.
Водный юнит сохраняет значения 100/10/2.5. Скорость атаки — 1.
Явные характеристики в createUnit имеют приоритет над настройками цвета.
